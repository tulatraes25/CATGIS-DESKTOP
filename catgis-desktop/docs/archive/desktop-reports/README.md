# Archived CATGIS Desktop reports

This directory contains historical audits, roadmaps, implementation reports, prompts, and status snapshots that previously lived in the `catgis-desktop/` project root.

They are preserved for traceability but are **not canonical descriptions of the current codebase**. Current build/runtime documentation should live under `catgis-desktop/docs/` or the repository root documentation.

Archived during the October 2026 repository sanitation.
